# OurAirports snapshot

Raw CSV files from https://davidmegginson.github.io/ourairports-data/
(`airports.csv`, `airport-frequencies.csv`, `runways.csv`), downloaded 2026-11-12.
Kept as-is; nothing here is edited by hand.

The CSV files are **gitignored** (about 18 MB), so a fresh clone does not have
them: download the three files above into this folder. Only this README is
tracked.

Used for: resolving a spoken destination to an airport, and as a fallback source
of airport positions and frequencies.

Licence: the project describes this data as public domain, but that wording was
not verified when the snapshot was taken (the data page failed to load). Check
https://ourairports.com/data/ before redistributing.

This is a snapshot, not a feed. It will go out of date; refreshing it means
downloading the same files again.
